# Run one read-only review

Open a file and use [Bachata: Review File](command:bachata.reviewFile), or review a selection from the editor menu. A context command prepares a draft; it does not submit it. Inspect the run contract, then send it.

This step completes when a read-only review run finishes.

Finishing means that this pass ended, not that the codebase is correct. Review the updated codebase again in a later, fresh session.
